# 담보평가 사전체크

FC 정보 입력 → 입력 검증 → Rule에 따른 적격 판단 → 정식 의뢰서 작성용 정보 반환.
진행 가능 건은 준법지원팀 사전 승인/이관 등록 없이 작성용 정보를 사용할 수 있습니다.
준법지원팀에는 예외 검토 건만 신규 등록합니다.

## 실행 및 배포

- Windows: Python 3.10 이상에서 `start_dashboard.bat` 더블클릭 → http://127.0.0.1:8080
- 개발 검증: `npm test`, `npm run build` (Node.js 22 이상)
- Vercel: `yn7844-maker/compliance777`, 브랜치 main, Root Directory ./, Framework Other, 빌드 npm run build, 출력 dist.
- 설정은 vercel.json에 포함. 웹 배포에는 Python/BGE가 필요하지 않습니다.
- 정적 앱에는 인증/권한/공용 DB가 없습니다. 비밀번호를 넣지 않은 콘텐츠 데모입니다.

## 입력 및 판정

- 주소는 필수. 마스킹된 주소를 복원하거나 생성하지 않습니다.
- 담당자/소속/업무 이메일은 작성용 선택 입력이며, 빠진 항목은 미입력으로 표시합니다.
- 권리관계는 미확인(U)으로 시작합니다. 선순위 채권/압류/가압류/전세권/기타 특이 권리를 각각 있음/없음으로 선택하고 확인 완료에 체크해야 합니다.
- 등기사항증명서 갑구/을구 조회 안내를 제공하지만 법률 해석이나 실제 조회를 자동화하지 않습니다.
- 선순위 채권금액은 선택 입력. 입력 시 0 이상의 정수만 허용하며 임계값 판정에 사용하지 않습니다.
- public 조회 미확인은 R004~R006으로 보완 필요를 반환합니다.
- 입력 검증은 Rule 적용 전 별도로 수행합니다. 새 법률 Rule을 추가하지 않았습니다.
- Rule 우선순위: R001 → R002 → R003 → R004~R006 → R099.
- 모든 Rule은 원문 Excel 미제공으로 데모 가정입니다. 최종 담보가액·법적 판단을 대체하지 않습니다.

## 반환 정보

- 주소/담당자/소속/이메일/채권금액/공개정보/권리관계/적용 기준/판정 사유를 표시합니다.
- 전체 복사, 항목별 복사, 직접 선택 가능한 전체 텍스트를 제공합니다.
- 진행 가능은 작성용, 보완/검토 필요 결과는 참고용으로 명확히 구분합니다.
- 수정 후에는 다시 입력 검증·판정하며, 확인한 권리관계가 자동으로 없음 처리되지 않습니다.

## 메뉴

홈 / 사전체크 / 의뢰내역 / 사례검색 / 준법지원팀 / 설정.
사례검색 내 사례 및 가이드 / 판정 기준. 준법지원팀 내 의뢰 관리 / 운영 대시보드.

## 예외 검토 및 보완

- 신규 이관은 준법지원팀 검토 필요 결과만 허용합니다.
- 상태: 처리 전 / 확인 중 / 보완 요청 / 승인 / 거부.
- 보완 요청 사유를 저장하고 담당 FC 수신 이메일을 입력해 Outlook 작성창을 엽니다. 입력한 수신 주소는 이관 기록에 저장하지 않습니다.
- FC는 기존 보완 요청 건에서 보완 후 재제출합니다. 주소 등 작성 정보는 저장하지 않으므로 다시 입력해야 합니다.
- 재판정 후 같은 접수번호에 이력을 추가합니다. 진행 가능으로 바뀐 경우에도 작성용 정보는 즉시 사용할 수 있으며 재제출은 별도입니다.
- 승인/거부는 예외 검토 처리 상태이며 Rule 판정·최종 담보평가 결과와 별개입니다.

## 이메일

보완 필요 결과에서는 담당자 업무 이메일로 보완 요청 작성창을 열 수 있습니다.
준법지원팀은 보완 요청 상태에서 FC 이메일을 입력해 작성창을 엽니다.
설정에서 PC·모바일 기본 메일 앱(Outlook) 또는 Microsoft 365 웹을 선택합니다.
자동 발송하지 않으며 사용자가 수신자·내용을 확인하고 직접 발송합니다. 발송 여부도 확인하지 않습니다.
자동 알림에는 공용 DB와 Microsoft Graph 또는 Power Automate의 회사 승인 연결이 필요합니다.
주소/담당자/금액은 메일 본문에 자동 포함하지 않습니다. 자격증명은 공개 소스에 넣지 않습니다.

## 저장 및 개인정보

- 입력한 주소·담당자·소속·담당자 이메일·채권금액은 메모리에서 반환·복사용으로만 사용합니다. 로그/이관 저장소에는 저장하지 않습니다.
- 사전체크 로그: localStorage `collateral.precheck.logs.v1`, timestamp/target_type/result/rule_id/rule_name/reason 6개 필드만 저장.
- 예외 이관: localStorage `collateral.precheck.requests.v1`, 개인 식별 정보 없이 입력 확인 플래그·판정·상태·처리 이력만 저장.
- 수신 설정: localStorage `collateral.precheck.mail.v1`, 사용자가 저장한 준법지원팀 수신 이메일과 작성 방식.
- 같은 브라우저·같은 웹주소에서만 유지됩니다. 직원 간 공유나 권한 분리가 구현된 서비스가 아닙니다.
- 인감증명서, 주민번호, 신분증, 민감 서류 업로드 기능은 없습니다.
- 샘플 데이터/사례는 실제 기록과 분리되어 표시됩니다.

## BGE 및 글꼴

BGE는 관련 문서 검색용이며 Rule 판정에 사용하지 않습니다. 웹 버전은 로컬 키워드 검색을 사용합니다.
로컬 실행 시 선택적인 python_backend 서버를 연결할 수 있으며 미연결 시에도 앱은 동작합니다.
Pretendard 1.3.9 가변 웹폰트를 fonts/에서 자체 제공합니다. 라이선스는 fonts/OFL.txt입니다.
